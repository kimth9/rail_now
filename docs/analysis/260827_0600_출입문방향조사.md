# 열차 출입문 방향 — 대피·경합역 나무위키 조사

- **일시**: 2026-08-27 06:00
- **목적**: "레일나우" 하차 알림 기능에서 "내리실 문은 왼쪽/오른쪽입니다"를 안내하기 위해, 완행/급행(또는 ITX-청춘)이 서로 다른 승강장에 정차해 문 방향이 바뀔 수 있는 대피(추월)역들의 실제 문 방향을 나무위키에서 조사한다. 대상 역 목록은 시각표 DB SQL 분석으로 사전에 확정됨.
- **스크립트**: 없음 — 웹 조사(Sonnet 서브에이전트 4개 병렬: 9호선 / 1호선 경부선계통 / 4호선·수인분당선 / 경춘선·경의중앙선)
- **입력**: 나무위키 각 역/노선 문서 (역명역, 노선명/역 목록, 노선명/급행 등)
- **산출물**: 이 문서
- **결과**: 조사 대상 총 24개 역(방향 세분 포함 시 약 30행) 중, 실제로 **"왼쪽/오른쪽" 문 방향이 나무위키에 명시적으로 서술된 곳은 3곳뿐**이다 — 1호선 병점역(상·하행), 1호선 수원역(하행), 경의중앙선 서빙고역(하행). 나머지는 승강장 번호·대피선 유무 같은 구조는 대부분 확인되지만 문 방향까지는 나무위키에 서술이 없어 "확인 안 됨"으로 남겼다(추측 없음). 또한 조사 과정에서 전제 자체가 맞지 않는 역들도 발견됐다: 9호선 송파나루·샛강·사평은 급행이 아예 통과(무정차)해 문방향 경합이 구조적으로 없고, 경춘선 대성리·김유정·망우는 ITX-청춘이 정차하지 않아 완행-ITX 간 승강장 경합이 발생하지 않는다.
- **후속**: (1) 문방향 미확인 역은 나무위키 외 출처(코레일 정차역 안내도, 실제 승차 경험 제보, 지도 기반 진행방향·좌우통행 역산)로 추가 검증 필요. (2) 경춘선 대성리·김유정·망우가 왜 "겹치는 역" 목록에 들어갔는지 시각표 DB의 열차종별 태깅을 재검토. (3) 병점·수원·서빙고에서 확인된 "평시 문방향 ↔ 대피/지연 시 문방향 전환" 패턴이 앱 로직에서 정적 매핑이 아니라 상황별 분기가 필요함을 시사 — 설계에 반영.

## 확인 못 한 역 / 상충되는 정보

- **문방향(왼쪽/오른쪽)이 나무위키에 명시적으로 서술된 곳은 3곳뿐이다**: 1호선 병점역(상·하행), 1호선 수원역(하행), 경의중앙선 서빙고역(하행). 나머지 역들은 승강장 번호·대피선 유무 같은 물리적 구조는 대부분 확인됐지만, 실제 나침반 방향(좌/우) 서술 자체가 나무위키 문서에 존재하지 않아 "확인 안 됨"으로 남겼다 — 승강장 트랙 배치 순서만으로 좌/우를 역산하려면 해당 구간의 좌측/우측통행 여부와 진행방향의 실제 지리적 방위가 필요한데 이 정보가 없어 추측하지 않았다.
- **9호선 송파나루·샛강·사평**: 급행이 아예 통과(무정차)하는 역이라 완행-급행 간 문방향 경합이 구조적으로 발생하지 않는다. "대피/경합역" 전제와 다르게 분류돼 있을 가능성이 있어 DB 재검토가 필요하다.
- **경춘선 대성리·김유정·망우**: ITX-청춘이 이 역들에 정차하지 않음이 나무위키에서 확인됐다(대성리는 상시 고속 무정차 통과, 김유정은 "완행만 정차하는 마지막 역", 망우는 ITX 정차역 목록에 없음). 완행-ITX 경합 전제가 성립하지 않으므로, 시각표 DB에서 왜 이 역들이 "겹치는 역"으로 잡혔는지(열차종별 태깅 오류 가능성) 재확인이 필요하다.
- **군포역**: 다른 경부선 대피역과 반대로 "완행이 본선, 급행이 부본선(저속 통과)"인 구조로 나무위키에 별도 서술돼 있다. 문방향은 확인 안 됨.
- **기흥역**: "완행=2·3번" 판단은 나무위키가 "급행=1·4번"이라고 서술한 것에서 역산한 것이며, 완행 쪽을 직접 명시한 문장은 없다 — 상충은 아니지만 간접 추론임을 표시해 둔다.
- **성환역**: "성환~화서 구간은 모두 왼쪽 문"이라는 일반 규칙이 성환역 문서 자체에는 있으나, 이 규칙이 적용되는 개별 역(오산·평택·수원 상행 등) 문서에서 독립적으로 재확인되지 않아 표에는 반영하지 않았다(참고용으로만 병기).
- **안산역·기흥역**: 나무위키의 "섬식 승강장"/"상대식 승강장" 총론 문서에 "좌측통행이면 섬식은 오른쪽 문·상대식은 왼쪽 문, 우측통행이면 그 반대"라는 일반 원칙이 있지만, 개별 트랙이 좌측/우측통행 중 무엇인지 명시한 문장이 없어 이 원칙을 대입해 결론 내리지 않았다.
