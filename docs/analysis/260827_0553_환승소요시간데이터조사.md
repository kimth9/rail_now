- **서울교통공사_서울 도시철도 환승정보** — [OA-22521](https://data.seoul.go.kr/dataList/OA-22521/F/1/datasetView.do) / [15098252](https://www.data.go.kr/data/15098252/fileData.do): 총 1,024행, 환승시작역/호선-하차 호차·문-환승종료역/호선-승차 호차·문 단위로 최단 환승경로와 소요시간 제공. 더 정밀하지만 역시 서울교통공사 1~8호선 한정.
- **범위 한계**: 두 데이터셋 모두 서울교통공사(1~8호선) 관할만 다룸. 코레일(KTX·일반철도), 공항철도, 신분당선, 인천교통공사, 부산·대구·대전·광주 등 타 도시철도와의 환승은 이 데이터에 없음. [전국대중교통환승센터표준데이터](https://www.data.go.kr/data/15034541/standard.do)는 이름이 비슷해 오해하기 쉬우나, 확인 결과 **버스-철도 복합환승시설(환승주차장 등 물리적 시설) 데이터**이지 역 내부 노선 간 도보 이동시간과는 무관함.
- 국가교통정보센터(TAGO), KTDB는 실시간 운행정보·교통수요 DB 중심이며 역사 내 환승 도보시간 데이터셋은 검색되지 않음. 부산교통공사 "역간 거리 및 소요시간 정보"([3033564](https://www.data.go.kr/data/3033564/fileData.do))는 인접역 간 주행시간 데이터로 보이고, 역사 내 환승 도보시간 데이터임은 확인하지 못함.

## 2. 상용 지도·위키 대안

- 네이버지도·카카오맵이 대중교통 길찾기에서 환승 대기·이동시간을 넉넉히 반영하는 것은 사실이나, **개발자용 오픈API로 환승 소요시간을 필드 단위로 제공하는 공식 API는 확인되지 않음**. 카카오모빌리티 길찾기 API는 자동차 내비 중심.
- 전국 단위 대중교통 API로 **ODsay LAB**이 있음. 경로 응답에 `totalWalk`/`totalWalkTime`(총 도보 거리·시간) 필드는 있으나 **환승 구간별 도보시간을 별도 필드로 제공하지는 않음**. 이용약관상 무료(Basic)는 6개월 한정·1,000회/일이고, "사전 협의 없이 대용량 호출 시 서비스 제한" 조항이 있어 **대량 수집(크롤링) 목적으로는 약관상 제약**이 있음.
- 나무위키에 [환승저항](https://namu.wiki/w/%ED%99%98%EC%8A%B9%EC%A0%80%ED%95%AD), [막장환승/예시/대한민국/수도권 전철](https://namu.wiki/w/%EB%A7%89%EC%9E%A5%ED%99%98%EC%8A%B9/%EC%98%88%EC%8B%9C/%EB%8C%80%ED%95%9C%EB%AF%BC%EA%B5%AD/%EC%88%98%EB%8F%84%EA%B6%8C%20%EC%A0%84%EC%B2%A0), [충정로역](https://namu.wiki/w/%EC%B6%A9%EC%A0%95%EB%A1%9C%EC%97%AD) 등 개별 문서에 통로 길이·소요시간이 서술형으로 산발적으로 기재됨(예: 신도림역 환승통로 평시 1분30초~혼잡시 3분30초, 2호선↔5호선 85m·2분 이내, 수원역 1호선↔수인분당선 300~400m·지하 4층 고저차). **전국 환승역을 일관된 표로 정리한 문서는 없음** — 개별 문서에 흩어져 있어 참고용 스팟 데이터로만 유용.

## 3. 작업 규모 추정

서울교통공사 자체 데이터 기준 145개 환승역 중 **300m 이상(=명백히 유의미한 지연 구간)은 단 7개역**뿐 — "모든 환승역"이 아니라 "극소수 최장거리 환승역"만 특별 관리가 필요하다는 가설이 수치로 뒷받침됨. 서울교통공사 관할 밖에서 나무위키가 반복 지목하는 막장환승역(서울역 1·4호선↔KTX/경의선, 수원역, 상봉역, 석계역, 부평역, 연신내역 등)을 더해도 **전국적으로 유의미한 대상은 대략 15~25개역 내외**로 추정 — 수작업(나무위키·역 안내도·현장 확인) 조사로 충분히 감당 가능한 규모.

## 4. 결론 및 권고

- **서울교통공사 관할(1~8호선) 145개역 + 1,024쌍 환승 데이터는 즉시 도입 권장**: 이미 정제된 공식 CSV가 무료로 존재하므로 스키마 매핑만 하면 되고, 추가 조사 부담이 거의 없음. `station_groups`에 `transfer_walk_time(from_stop_id, to_stop_id, seconds, source='seoul_metro_official')` 같은 보조 테이블 하나 추가로 충분.
- **서울교통공사 밖(코레일·신분당선·공항철도·지방 4개 도시)은 공식 데이터가 없으므로 이번 단계에서는 스킵 권장**. 대상이 300m급 극소수 역뿐이라 언젠가 나무위키·현장 사진 기반 수작업으로 채울 가치는 있지만, 지금은 앱 착수 전 시각표 파이프라인 구축이 우선이며 환승시간은 부가 기능이므로 후순위로 미루는 편이 합리적.
- **권장 순서**: 1단계 — 서울교통공사 공식 데이터 흡수(비용 거의 없음) / 2단계(추후) — 나머지 15~20개 막장환승역 나무위키·수작업 보완.
