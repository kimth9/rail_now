- **입력**: 서울 열린데이터광장, 공공데이터포털, SK Open API 문서, 각 교통공사 홈페이지 — 상세 URL은 아래 결과 참조

- **결과**: 아래 상세
- **후속**: 지금 단계에서는 보류. 앱이 서울 1~8호선만이라도 상용화된 뒤, "실시간 아님"을 명시한 시간대별 평균 혼잡도 부가정보로 재검토. `future_plan.md`에 반영 여부는 별도 판단.

## 1) 확인된 소스

실제 검색·접속으로 확인한 것은 총 4개 계열이다. 그 외(부산·대구·대전·광주 교통공사, 코레일 통계 API)는 "혼잡도" 자체가 아니라 승하차 인원수만 있거나, 자료가 없었다.

### ① 서울교통공사 지하철혼잡도정보 (1~8호선)
- 서울 열린데이터광장 [OA-12928](https://data.seoul.go.kr/dataList/OA-12928/F/1/datasetView.do), 공공데이터포털 [서울교통공사_지하철혼잡도정보_20260331](https://www.data.go.kr/data/15071311/fileData.do)
- 통계치. 실시간 아님 — "30분 단위 평균 혼잡도"(해당 시간대 통과 열차들의 평균)
- 서울교통공사 1~8호선만. 9호선·인천·부산·대구·대전·광주는 미포함
- 파일(CSV/XLSX) 다운로드는 인증키 불필요, Open API(XML/JSON)는 공공데이터포털 회원가입 후 활용신청 필요(무료)
- 분기별 갱신(2024년부터), 최근 등록 2026-04-21, 다음 예정 2026-08-15
- 역 단위(요일구분·호선·역번호·상하선·30분 단위 %). 열차/칸 단위 아님

### ② 서울시 9호선 혼잡도 정보 (별도 사업자)
- [OA-22197](https://data.seoul.go.kr/dataList/OA-22197/F/1/datasetView.do)
- 통계치, 9호선 한정, 인증키 요건 페이지에 명시 안 됨(Open API는 별도 문의), 연 단위 갱신, 역 단위(6칸 열차 922명=100% 기준)
- 1~8호선과 자료 체계·갱신주기가 달라 병합 시 주의 필요

### ③ SK텔레콤 지오비전 퍼즐 — 지하철 혼잡도 API
- [openapi.sk.com/products/detail?svcSeq=54](https://openapi.sk.com/products/detail?svcSeq=54), TMAP 칸 혼잡도 문서 [transit.tmapmobility.com/docs/puzzle/car](https://transit.tmapmobility.com/docs/puzzle/car)
- 두 종류 병존: "경로/칸 혼잡도"는 통계성(요청 시간과 동일 요일·시간대 과거 데이터 반환), 별도로 "실시간 열차 혼잡도"도 제공(2·3호선 위주로 언급됨)
- TMAP 문서 기준 서울 1~9호선 + 공항철도 + 신분당선. 지방 도시철도 커버 여부는 확인 안 됨
- SK Open API 회원가입 후 appKey 발급. 요금제는 무료체험(Free)·후불 종량제(Basic)·대량용 별도 견적 — 완전 무료는 아니고 사용량에 따라 과금
- 정확한 갱신주기는 문서상 확인 못 함(공식 문의 필요). 단위는 열차/칸(160명=100%) — 서울교통공사 통계보다 세밀함

### ④ 대구교통공사 승하차인원 데이터
- [대구교통공사_역별일별시간별승하차인원현황](https://www.data.go.kr/data/15002503/fileData.do) 등
- "혼잡도"가 아니라 시간대별 승하차 인원수 원자료 — 혼잡도로 쓰려면 자체 가공(열차 정원 대비 환산) 필요. 월 단위 갱신, 2018년부터 존재
- 부산·대전도 동일하게 승하차 인원 데이터만 확인됨(혼잡도 % 자체는 없음). 광주는 역별 승하차 통계 자체가 없다는 서술을 확인 — 사실상 "없음"

## 2) 코레일 광역전철(1호선·경의중앙선·경춘선·수인분당선 등)

공공데이터포털에 [한국철도공사_수도권 전철 혼잡도_20181231](https://www.data.go.kr/data/15088856/fileData.do)이 존재하지만, 실데이터 기준일이 2018-12-31이고 갱신주기가 "수시(1회성 데이터)"로 표기돼 이후 갱신된 흔적이 없다 — 사실상 방치된 죽은 데이터셋이다. 메타데이터 수정일 2025-09-02는 페이지 정보 갱신일 뿐 실데이터 갱신이 아니다. 코레일 자체 홈페이지(info.korail.com)의 광역열차 정보 페이지는 운행현황·노선 정보 위주이며 혼잡도 수치는 확인되지 않았다. **코레일 구간은 신뢰할 만한 혼잡도 소스가 사실상 없음.**

## 3) 결론 및 추천

지금 단계에서 "레일나우"에 담기에는 시기상조로 판단한다.

- **커버리지 단절**: 서울교통공사 1~8호선만 안정적 소스가 있고, 9호선은 별도 체계, 코레일 광역전철은 사실상 없음, 지방 5개 도시(부산·대구·대전·광주·인천)는 원자료(승하차 인원)뿐이라 자체 가공이 필요하다. "한국 전체 철도"를 다루는 이 프로젝트 성격상 반쪽짜리 기능이 된다.
- **실시간성 부재**: 무료 공식 소스는 전부 "30분 단위 과거 평균" 통계이지 실시간이 아니다. 실시간에 가까운 것은 SK 지오비전(유료, appKey 발급·과금 필요)뿐이며 커버리지도 제한적이다.
- **구현 난이도 대비 가치**: 서울교통공사 데이터 자체는 파일 다운로드로 손쉽게 붙일 수 있으나(분기 CSV 병합), "혼잡도 표시"가 실시간 위치추적 앱의 핵심가치(접근·하차 알림)에 직접 기여하지 않고 부가정보에 그친다.

**재검토 조건**: (1) 앱이 서울 1~8호선 사용자만이라도 먼저 상용화 단계에 들어가고, (2) 부가기능으로 "시간대별 평균 혼잡도 참고 정보"(실시간 아님을 명시)를 추가할 여력이 생기면, 그때 서울교통공사 분기 CSV를 `stop_times`에 요일·시간대 매핑해 붙이는 정도가 비용 대비 가장 합리적이다. SK 유료 API는 실시간성이 필요해지고 예산이 확보된 이후에나 검토할 것.
